# Customer Shopping Data Analysis

## Overview

This project focuses on cleaning and analyzing a raw customer shopping dataset using Python. The analysis demonstrates practical data cleaning, feature engineering, exploratory data analysis (EDA), and data visualization.

The project starts with a deliberately messy dataset containing missing values, duplicate records, inconsistent categorical values, invalid numerical values, and incorrect data types.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow

### 1. Data Inspection
- Examined dataset dimensions and column information
- Checked data types and missing values
- Identified duplicate records
- Reviewed unique and categorical values
- Examined numerical distributions

### 2. Data Cleaning
- Removed duplicate records
- Handled missing Age values using the median
- Replaced missing City values with `Unknown`
- Handled missing Quantity values using the median
- Removed invalid Quantity values
- Converted Price to numeric and handled invalid values
- Standardized inconsistent Gender and Category values
- Handled missing Payment Method values
- Corrected invalid Age values
- Converted Purchase Date to datetime format

### 3. Feature Engineering

Created a `Total_Sales` column:

`Total_Sales = Quantity × Price`

Also extracted the month from `Purchase_Date` for monthly analysis.

### 4. Exploratory Data Analysis

The analysis explored:

- Customer distribution by gender
- Purchases by product category
- Product-level purchase counts
- Revenue generated by each product
- Revenue generated by each city
- Monthly purchase trends
- Monthly revenue
- Average transaction value

### 5. Data Visualization

Created visualizations using Matplotlib, including:

- Category distribution pie chart
- Category purchase bar chart
- Product revenue bar chart
- Monthly revenue line chart
- Price vs Quantity scatter plot

## Key Insights

- Total revenue generated: **₹353,328**
- Total valid transactions: **122**
- Average revenue per transaction: **₹2,896.13**
- Accessories was the most purchased category with **82 purchases**
- Laptop Bag generated the highest product revenue at **₹73,830**
- Bangalore generated the highest total sales among the cities
- June recorded the highest number of purchases with **28 transactions**
- May generated the highest monthly revenue
- Electronics had the highest average transaction value among the categories

## Files

- `customer_shopping_analysis.ipynb` — Complete analysis and visualizations
- `customer_shopping_raw.csv` — Original raw dataset
- `customer_shopping_cleaned.csv` — Cleaned dataset after preprocessing

## Conclusion

This project demonstrates a complete beginner-to-intermediate data analysis workflow, starting from raw and inconsistent data and transforming it into a clean dataset suitable for exploratory analysis and visualization.
